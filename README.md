# Portal Gun Mod

Add functional portal guns and a coordinate menu to Minecraft Bedrock.

## Features

- Adds portal guns with 3D models
- Includes a coordinate menu for managing portals

## Requirements

- Minecraft Bedrock Edition 1.20.1
- Minecraft Forge 47.1.0

## Installation

1. Download the mod from the releases page.
2. Place the mod file in your Minecraft mods folder.
3. Launch Minecraft and enjoy your new portal guns!

## Usage

1. Craft a portal gun using the provided recipe.
2. Right-click to open the coordinate menu.
3. Use the menu to set coordinates, manage dimensions, and control portal behavior.

## Configuration

The mod includes a configuration file that allows you to customize various aspects of the portal guns and menu. Edit the configuration file to your liking.
